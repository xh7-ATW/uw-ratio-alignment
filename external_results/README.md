# Reference Results

This directory stores external benchmark outputs used as comparison baselines
for paper figures. These are not new runs produced by the public reproduction
scripts in this directory.

- `benchmark_9_normuon_u_w_floor/`, `benchmark_10_normuon_weight_decay/`, and
  `benchmark_30_projection_pruning/`: externally obtained public benchmark
  logs used for the Figure 1(a) u/w-floor comparison against weight-decay and
  pruning controls.
